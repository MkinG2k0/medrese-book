# Requirements: Электронный дневник медресе

**Defined:** 2026-10-31  
**Core Value:** Учитель и менеджер видят реальный прогресс каждого ученика и могут вовремя вмешаться  
**Milestone:** v3.0 Касса и долги по месяцам

## v3.0 Requirements

Scope волны 1: роли кассы, оплата/долг по месяцам, убрать «Сальдо».  
(Источник: требования Камы 31.10.2026 + уточнения 31.10.2026.)

### Roles & cash desk

- [ ] **CASH-01**: В системе есть роль **Кассир** (`CASHIER`) с доступом к сценариям приёма/подтверждения наличных
- [ ] **CASH-02**: Кассир может **только подтверждать наличные** платежи; остальные бухгалтерские операции ему недоступны
- [ ] **CASH-03**: Бухгалтер (`ACCOUNTANT`) сохраняет **полный доступ** ко всем операциям бухгалтерии (включая то, что делает кассир)

### Tuition by month

- [ ] **TUITION-01**: Заявка на оплату опекуна содержит **один месяц** на всю заявку (все выбранные дети — тот же месяц)
- [ ] **TUITION-02**: На экране оплаты опекун выбирает месяц в селекте/календаре, где **сразу видны неоплаченные месяцы**
- [ ] **TUITION-03**: Бухгалтер видит и ведёт долг ученика/опекуна **по месяцам** (за какой месяц долг)
- [ ] **TUITION-04**: Кассир видит, **за какой месяц** опекун не оплатил

### Payments UI

- [ ] **PAYUI-01**: В таблице платежей учеников колонка **«Сальдо»** убрана
- [ ] **PAYUI-02**: Экспорт Excel платежей **не содержит** колонку «Сальдо»
- [ ] **PAYUI-03**: Статусы оплаты (Аванс / Оплачено / Долг и т.п.) продолжают отображаться без колонки сальдо

## Future Requirements

Отложено на следующие волны (не в roadmap v3.0).

### v3.1 — ЗП 3.0, явка, окна

- **SAL-01**: ЗП = часы × ставка × мужской коэффициент (дефолт выдаётся, меняет менеджер)
- **SAL-02**: За месяц начисления: если опозданий на работу &lt; 3 → надбавка +1000 ₽
- **SAL-03**: Опоздание на урок: минуты = факт старта − начало окна; −10 ₽ / мин
- **SAL-04**: Аттестация (= квалификация = ПК): 1000 ₽ × N; действует полгода; начисляется каждый месяц периода
- **SAL-05**: Надбавка за выходной день (учителя не работают): только при N≥1; 600 + 50×N ₽/день (мин. 650 при N=1)
- **SAL-06**: Выдача ЗП до 10-го числа
- **ATTEND-01**: Кнопки «Я пришёл» / «Завершить рабочий день»; уроки и оценки только в этом интервале
- **WINDOW-01**: Система окон учителей с редактированием (источник старта урока для SAL-03)

### v3.2 — Каникулы

- **HOL-01**: Глобальный календарь каникул на школу
- **HOL-02**: На каникулах окна/прогулы/штрафы не считаются (отрубаются)

### v3.3 — Партнёр и переписки

- **PART-01**: Роль Партнёр: внос donation + просмотр «сколько всего пожертвовал»
- **CHAT-M-01**: Переписки между менеджерами
